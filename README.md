## Über das Projekt
Barrier Spotter ist ein Projekt, das Menschen mit diversen Behinderungen im Alltag unterstützen soll.
Es basiert auf einem Community Gedanken wo Able Bodied Menschen gemeinsam mit Betroffenen eine online Datenbank mit Informationen über mögliche Barrieren in ihrem lokalen Umfeld füllen.

Der Funktionsumfang ist bewusst klein gehalten um einfach bedienbar und übersichtlich zu sein. Basierend auf Community Feedback können weitere Funktionen in Zukunft ergänzt werden.

Das Projekt ist im Rahmen einer Projektarbeit an der Technischen Hochschule Köln entstanden.
